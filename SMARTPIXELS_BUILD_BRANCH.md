# SmartPixels for oz7wm / Android 17 (build branch)

This branch builds a pinned upstream SmartPiXelsPosed (AGPL-3.0) plus a ROM-specific overlay adapter for rodin. This does NOT modify the ROM or SystemUI.apk. The resulting APK requires an Xposed-compatible framework (Vector/LSPosed) and the companion KernelSU zip to enable its guard property. Test on device and keep rollback available. The binary source package is xz-compressed in `smartpixels_build_source.tar.xz`. The original project is at https://github.com/frknkrc44/SmartPiXelsPosed.
